Site Plan

Site Name

The planned name for the website is "tattleweb.com" This is because the intended purpose for this website is as a mock "social media" where users can come to share gossip and news ("tattle") in their local area

Purpose

As mentioned, the website is a mock social media site centered around local gossip and interest. It will provide a way to connect with other people around the world to share interesting things otherwise not shared.

Scenarios

  • What is happening in X city?
  • How can I remain anonymous while I post about my neighbors?
  • I dont like X user, how can I not see them?
  • X post is offensive, how can I remove it?

Color Scheme

Several color schemes are planned for the website, the fallback color scheme is the default lime (#FF0000) on a dark green background (#051005), reminiscent of old monochrome CRT monitors.
